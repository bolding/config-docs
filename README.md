# pygetm-config documentation

Documentation of pygetm-config, an introspection-driven configuration schema for
[pyGETM](https://github.com/BoldingBruggeman/getm-rewrite), published with GitHub Pages:
**https://bolding.github.io/config-docs/**

This repository holds only the generated site. The pages are built from pygetm-config's
`README.md` and `docs/` (not public yet) with `tools/web/site.py`, so edits made here
directly are overwritten.
